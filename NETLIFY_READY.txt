┌──────────────────────────────────────────────────────────────────────┐
│  🚀 COMO FAZER O DEPLOY (3 PASSOS)                                   │
└──────────────────────────────────────────────────────────────────────┘

  PASSO 1: Criar Banco de Dados (5 minutos)
  ┌────────────────────────────────────────────────────┐
  │ 1. Acesse: https://supabase.com                    │
  │ 2. Create new project                              │
  │ 3. Copie DATABASE_URL (Settings → Database)        │
  │ 4. Execute migrations SQL                          │
  │ 5. Execute database/init.sql                       │
  └────────────────────────────────────────────────────┘

  PASSO 2: Configurar Netlify (5 minutos)
  ┌────────────────────────────────────────────────────┐
  │ 1. Login: https://app.netlify.com                  │
  │ 2. Add new site → Import from Git                  │
  │ 3. Selecione repositório banking-system            │
  │ 4. Settings → Environment variables                │
  │ 5. Adicione variáveis de .env.netlify              │
  │    • DATABASE_URL (do Supabase)                    │
  │    • JWT_SECRET (único e aleatório!)               │
  │    • FRONTEND_URL (seu-site.netlify.app)           │
  │    • VITE_API_URL (seu-site.netlify.app)           │
  │    • PULSE_CLIENT_ID, PULSE_API_KEY, etc          │
  └────────────────────────────────────────────────────┘

  PASSO 3: Deploy! (2-3 minutos)
  ┌────────────────────────────────────────────────────┐
  │ 1. Clique "Deploy site"                            │
  │ 2. Aguarde build (2-3 min)                         │
  │ 3. Site no ar! 🎉                                  │
  └────────────────────────────────────────────────────┘

  ⏱️  TEMPO TOTAL: ~15 minutos

│  ⚠️  IMPORTANTE                                                      │
└──────────────────────────────────────────────────────────────────────┘

  🔐 SEGURANÇA:
     • Mude JWT_SECRET para valor único e aleatório
     • Use DATABASE_URL do seu banco externo
     • Atualize todas as URLs com seu domínio Netlify
     • Mude senha do admin após primeiro login

  🗄️ BANCO DE DADOS:
     • Netlify NÃO hospeda PostgreSQL
     • Use Supabase (grátis, 500MB)
     • Ou Railway, ElephantSQL, etc
     • Execute TODAS as migrations

  📊 PLANO GRATUITO:
     • 100GB bandwidth/mês
     • 125k function invocations/mês
     • 10 segundos timeout/function
     • Suficiente para começar!
