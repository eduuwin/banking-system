                   🚀 FLUXO DE INÍCIO

┌─────────────────────────────────────────────────────────────┐
│                 MÉTODO 1: SCRIPT (MAIS FÁCIL)               │
└─────────────────────────────────────────────────────────────┘

    1️⃣  Clone o repositório
         git clone https://github.com/eduuwin/banking-system.git
                           │
                           ▼
    2️⃣  Entre na pasta
         cd banking-system
                           │
                           ▼
    3️⃣  Execute o script
         ./start.sh  (Linux/Mac)
         start.bat   (Windows)
                           │
                           ▼
    ✅  Sistema rodando!
         Frontend: http://localhost:3000
         Backend:  http://localhost:5000

┌─────────────────────────────────────────────────────────────┐
│              MÉTODO 2: DOCKER COMPOSE DIRETO                │
└─────────────────────────────────────────────────────────────┘

    1️⃣  Clone o repositório
                           │
                           ▼
    2️⃣  Configure o .env
         cp .env.example .env
                           │
                           ▼
    3️⃣  Inicie com Docker
         docker-compose up --build
                           │
                           ▼
    ✅  Sistema rodando!

┌─────────────────────────────────────────────────────────────┐
│              MÉTODO 3: DESENVOLVIMENTO LOCAL                │
└─────────────────────────────────────────────────────────────┘

    1️⃣  Configure PostgreSQL
                           │
                           ▼
    2️⃣  Inicie Backend
         cd backend && npm install && npm start
                           │
                           ▼
    3️⃣  Inicie Frontend
         cd frontend && npm install && npm run dev
                           │
                           ▼
    ✅  Sistema rodando!
